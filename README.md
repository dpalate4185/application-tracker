# Job Hunt Tracker

A personal job application tracker: https://dpalate4185.github.io/application-tracker/

- Track company, role, status, job type, dates, follow-ups, resume version, contacts and notes
- Pipeline counts, response rate and follow-up reminders
- Works on phone and desktop, synced through a private Google Sheet
- Download everything as an Excel file

This repo holds only the website. No application data is stored here: entries live in the owner's private Google Sheet, reachable only with a passcode. See [SETUP.md](SETUP.md).
